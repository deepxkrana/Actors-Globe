# ActorsGlobe

ActorsGlobe is a full-stack casting platform connecting actors and casters.

## Current Status

- Project structure initialized
- Frontend: React + Vite + TypeScript
- Backend: Node.js + Express + TypeScript
- Database: PostgreSQL + Prisma
- Authentication development in progress

## Branches

- `main` — stable project baseline
- `feature/auth` — authentication development
